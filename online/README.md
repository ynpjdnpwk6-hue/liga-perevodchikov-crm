# Лига переводчиков — сайт и CRM

Главная страница: https://liga-perevodchikov-crm.silky-globe-7217.chatgpt.site/
Регистрация и вход: `/login`, кабинет следователя: `/investigator`, CRM: `/admin`.

Сайт публичный. Главная представляет услуги Лиги в Волгограде, а личные данные защищены серверной авторизацией. Следователям не нужны ChatGPT и внешние приглашения: они регистрируются по номеру телефона и паролю.

## Первое использование

Следователь указывает ФИО, телефон, пароль от 12 символов и при желании организацию. Номер пока не подтверждается SMS. При регистрации выдаётся личный код восстановления — его нужно сохранить отдельно. Затем можно сразу отправить заявку: язык, дата и время по Москве, место и комментарий. Она поступает в CRM со статусом «Новая», нулевой стоимостью и без назначенного переводчика.

Первый вход владельца: ссылка «Первый вход владельца CRM» на странице входа, через прежний аккаунт ChatGPT. В CRM откройте «Следователи» → «Мой вход по телефону», задайте свой номер и пароль, сохраните код восстановления. После этого владелец тоже входит по телефону; аккаунт ChatGPT для последующих входов не нужен. Прежний способ входа владельца сохранён.

В разделе «Следователи» видны самостоятельные регистрации. Отключение доступа завершает сессии и блокирует кабинет, сохраняя историю. Старые учётные записи по email сохранены в «Доступ по email», но для новых регистраций они не требуются. Совпадение телефона с чужой карточкой заказчика никогда автоматически не связывает учётные записи и не открывает чужие заявки.

## Защита и данные

- Личность и роль проверяются на сервере для каждого API. Только владелец может настроить административный вход по телефону; самостоятельная регистрация всегда создаёт роль следователя.
- Пароли: PBKDF2-HMAC-SHA256, 600 000 итераций, отдельная случайная соль. Пароли не записываются в открытом виде.
- Случайные 256-битные токены сессий хранятся только как SHA256-хеши. Cookie `__Host-liga_session` имеет Secure, HttpOnly, SameSite=Strict и Path=/ без Domain. Сессия действует 12 часов.
- Регистрация, вход, восстановление и настройки требуют CSRF-токен и правильный Origin. Лимиты попыток хранятся в D1 и действуют между экземплярами Worker. При недоступном доверенном IP применяется общий резервный лимит.
- Код восстановления — случайный 256-битный секрет; на сервере хранится только хеш. Восстановление меняет пароль и код, аннулирует старый код и все прежние сессии.
- Следователь получает только свои заявки. Финансы, телефоны переводчиков, внутренние заметки и чужие обращения в кабинет не передаются. Исходный комментарий следователя хранится отдельно.
- Публичные регистрации до первого входа владельца сохраняются с временной областью `liga-public-pending`. При первом входе проверенный владелец присоединяет эти новые строки к своей CRM. Имеющиеся записи других областей не переписываются; посетитель не может стать владельцем.
- Связанные изменения и журнал выполняются транзакционным D1 batch. Для правок проверяется revision. Старые миграции не изменяются.

Платформенная личность владельца сверяется с секретным окружением `LIGA_ADMIN_EMAIL` и стабильным идентификатором владельца в таблице `league`. Изменение email окружения не передаёт право на существующую CRM. Не храните реальные номера, пароли, коды, cookie и секреты в исходном коде.

## Поисковики

Главная возвращает обычный HTML без входа: заголовок, описание услуг, canonical, Open Graph и структурированные данные Organization. `robots.txt` указывает на `sitemap.xml`; карта содержит только главную и страницу обработки данных. CRM, вход, кабинеты и API исключены из карты и получают noindex; авторизация защищает сами данные независимо от robots.txt.

Техническая подготовка не гарантирует появление в выдаче или позиции. Для управляемой индексации владелец может подтвердить сайт в Google Search Console и Яндекс Вебмастере и отправить sitemap. Эти кабинеты пока не подключены и запрос на индексацию от их имени не отправлялся. Покупка собственного домена не выполнялась.

## Возможности CRM

Заказчики, переводчики и языки, заявки и статусы, назначение активного переводчика с нужным языком, CSV для Excel, конфликт правок и журнал. Комиссия Лиги — 30%, доля переводчика — 70%; суммы хранятся в целых копейках, комиссия округляется HALF_UP. Сводка включает выполненные заявки, задолженность равна комиссии минус полученной комиссии. Оплата заказчиком и налоги не учитываются.

## Разработка и проверки

Vinext, Cloudflare Workers, D1, Drizzle. Основные файлы: `app/public-home.html`, `app/login/`, `public/auth.js`, `app/admin/`, `app/investigator/`, `app/api/phone-auth.ts`, `app/api/portal-service.ts`, `app/api/service.ts`, `db/schema.ts`, `drizzle/`.

```bash
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
node --check public/app.js
node --check public/portal.js
node --check public/auth.js
./node_modules/.bin/tsc --noEmit --incremental false
pnpm build
```

13 групп проверок выполняют производственные SQL-запросы на SQLite: финансовые расчёты и ограничения, конфликты правок, миграции с сохранением данных, изоляция следователей, регистрация без ChatGPT, заявки до первого входа владельца, пароли и сессии, восстановление и вращение кодов, выход и срок сессии, CSRF и Origin, ограничение попыток, отключение доступа и запрет самостоятельного повышения роли. Адаптер prepared/batch не заменяет реальную D1-инфраструктуру. PBKDF2 с 600 000 итераций также проверен в Worker-совместимом runtime. Браузерная визуальная проверка недоступна в среде.

Публикация через Sites сохраняет базу и применяет добавочные миграции. `.openai/hosting.json` хранит только идентификатор проекта и логический binding DB. Записи для проверок существуют только в памяти тестов и не загружаются в рабочую базу. Исходный код синхронизируется в GitHub в `online/`; исходная локальная Python-версия сохранена отдельно.

## Ограничения

SMS-подтверждение, восстановление через SMS, Telegram, кабинеты переводчиков, платежи, договоры и проверка пересечения расписания не подключены. Телефон является логином, а не подтверждением личности или принадлежности к ведомству. Следователь пока не редактирует и не отменяет отправленные заявки — это делает администратор. В интерфейсе отсутствует удаление: отключение доступа не удаляет данные. Сайт не гарантирует недопущение прямого обмена контактами между следователем и переводчиком.
